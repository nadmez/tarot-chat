# server

Express tabanlı API. Node 20+ ve npm ile çalışır.

## Kurulum

Monorepo kökünden:

```bash
npm install
```

Yalnızca bu paket için geliştirme:

```bash
npm run dev -w server
```

## Üretim

```bash
npm run build -w server
npm start -w server
```

`.env` dosyası için `.env.example` dosyasına bakın.
